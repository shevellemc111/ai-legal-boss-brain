# AI Legal Boss Brain

The Firm Brain Builder kit for **AI Powered Law Firm Live**, by Shevelle McPherson, Esq.

## Install (Claude desktop app → Cowork)

1. Open **Customize** in the sidebar, then **Plugins**.
2. Choose **Add marketplace** and paste: `shevellemc111/ai-legal-boss-brain`
3. Find **ai-legal-boss-brain** and click **Install**.

When new skills are added, open the marketplace and click **Update**.

**Prefer a file?** Download `ai-legal-boss-brain.plugin` from the class materials and use the upload option on the Plugins page.

> Plugins work in Cowork and Claude Code, not regular Chat.

See [the plugin README](plugins/ai-legal-boss-brain/README.md) for what's included.
